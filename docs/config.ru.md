# Настройка PV-Transcribe

[README на русском](../README.ru.md) | [English README](../README.md)

Конфиг лежит в `plugins/PV-Transcribe/config.yml`. Менять настройки можно двумя способами:

- отредактировать файл и выполнить `/vtt reload`;
- прямо в игре: `/vtt set <параметр> <значение>`, например `/vtt set subtitles.style.preset dark`. Tab подсказывает параметры и значения, изменение сразу сохраняется в config.yml. `/vtt get [раздел]` показывает текущие значения (ключи API скрыты).

Ниже весь конфиг по умолчанию с комментариями на русском. В самом файле комментарии на английском, значения и названия параметров те же.

```yaml
# ============================================================================
#  PV-Transcribe - распознавание речи из Plasmo Voice в реальном времени
# ============================================================================
# Применить изменения: /vtt reload

config-version: 2

# Главный выключатель распознавания.
enabled: true

# Язык сообщений плагина: en или ru (файлы в plugins/PV-Transcribe/lang/, их можно править).
locale: en

transcription:
  # Язык распознавания (код ISO: en, ru, de, ...). В игре: /vtt language <код>.
  # Движку vosk нужна отдельная модель для каждого языка (см. engine.vosk.models).
  language: en
  # Определять язык речи автоматически (/vtt language auto).
  # Умеют только облачные движки (openai, deepgram); vosk и t-one берут "language".
  auto-detect-language: false
  # Показывать промежуточный текст, пока игрок ещё говорит.
  partial-results: true
  # Не чаще одного промежуточного результата на игрока за столько миллисекунд.
  partial-interval-ms: 150
  # Если от игрока нет звука столько времени, считается, что он замолчал.
  silence-timeout-ms: 900
  # Непрерывная фраза принудительно завершается через столько секунд.
  max-phrase-seconds: 20
  # Потоки распознавания (0 = автоматически: половина ядер процессора, от 1 до 4).
  # Распознавание никогда не идёт в главном потоке сервера.
  worker-threads: 0
  # Сколько игроков может распознаваться одновременно.
  max-concurrent-speakers: 32
  # Если распознавание отстаёт от речи больше чем на столько, лишний звук отбрасывается (защита от лагов).
  max-queue-ms: 3000
  # Распознаватели молчащих игроков освобождаются через столько секунд.
  idle-recognizer-close-seconds: 60
  # Миры без распознавания. В игре: /vtt world <мир> on|off
  disabled-worlds: []

engine:
  # Движок распознавания. В игре: /vtt engine <тип>.
  #   auto     - t-one для русского, vosk для остальных языков (облачный движок, если включено автоопределение и задан ключ)
  #   vosk     - офлайн, бесплатно, много языков; подбирает слова из своего словаря, поэтому редкие слова и ники страдают
  #   t-one    - офлайн, бесплатно, только русский; пишет то, что слышит, по буквам
  #   deepgram - облако (платно, новым аккаунтам дают бесплатный кредит); очень точно, быстро, с пунктуацией, ники игроков как подсказки
  #   openai   - облако (платно); любые языки, автоопределение языка, ники игроков как подсказки
  # Облачные движки отправляют голос игроков провайдеру, пока они говорят. Предупредите об этом игроков.
  type: auto
  deepgram:
    # Ключ создаётся на https://console.deepgram.com
    api-key: ""
    model: nova-3
    # Пауза (мс), после которой Deepgram завершает фразу.
    endpointing-ms: 500
    # Отправлять ники игроков онлайн как keyterms, чтобы они писались правильно.
    player-names-as-keyterms: true
  openai:
    # Ключ создаётся на https://platform.openai.com/api-keys
    api-key: ""
    # Модель распознавания (см. документацию OpenAI Realtime transcription).
    model: gpt-live-transcribe
    # Необязательная подсказка о разговоре, например "Minecraft players talking in voice chat".
    prompt: ""
    player-names-as-keywords: true
  t-one:
    # Файл модели в папке плагина; скачивается автоматически (~140 МБ).
    model-file: models/t-one/model.onnx
    auto-download: true
    download-url: "https://huggingface.co/t-tech/T-one/resolve/main/model.onnx"
    # Пауза (мс), после которой фраза завершается.
    silence-ms: 600
  vosk:
    # Папка с моделями внутри папки плагина.
    models-folder: models
    # Скачать модель при первом запуске, если её нет.
    auto-download: true
    download-url: "https://alphacephei.com/vosk/models/{model}.zip"
    # Модель для каждого языка. Все модели: https://alphacephei.com/vosk/models
    # Маленькие модели (~40-50 МБ) работают в реальном времени на любом процессоре; большие точнее, но требуют гигабайты RAM.
    # Вместо названия можно указать абсолютный путь к папке модели.
    models:
      en: vosk-model-small-en-us-0.15
      ru: vosk-model-small-ru-0.22
      de: vosk-model-small-de-0.15
      fr: vosk-model-small-fr-0.22
      es: vosk-model-small-es-0.42
      uk: vosk-model-small-uk-v3-small
      pl: vosk-model-small-pl-0.22

subtitles:
  # Показывать облачка над говорящими игроками.
  enabled: true
  # Показывать текст, пока игрок ещё говорит (он растёт по словам).
  show-partial: true
  # Показывать ник игрока первой строкой облачка (обычная табличка с ником и так видна).
  show-name: false
  name-format: "&e{name}:"
  # Начинать фразы с заглавной буквы.
  capitalize: true
  # До стольких облачков над игроком: новая фраза появляется сразу над головой,
  # старые поднимаются выше, самая старая исчезает.
  max-bubbles: 3
  # Максимум слов в одном облачке; длинная речь продолжается в новом облачке.
  max-words-per-bubble: 10
  # Перенос строк в облачке: максимум символов в строке и максимум строк.
  # Если текст длиннее, показывается его конец, а начало заменяется на "…".
  max-line-length: 32
  max-lines: 3
  # Сколько держится законченная фраза (секунды)...
  display-seconds: 3.5
  # ...плюс столько мс на каждый символ, чтобы длинные фразы успевали прочитать...
  display-ms-per-character: 40
  # ...но не дольше этого (секунды).
  max-display-seconds: 8
  # Плавное исчезновение в конце (мс).
  fade-out-ms: 500
  # Высота нижнего облачка над головой игрока (блоки). 0.85 = сразу над обычной табличкой с ником.
  height: 0.85
  # Расстояние по вертикали между облачками (блоки).
  bubble-spacing: 0.07

  # Внешний вид облачка.
  # Minecraft рисует фон текста только прямоугольным, скруглённые углы невозможны
  # без ресурспака; всё ниже работает у игроков без модов и ресурспаков.
  style:
    # Готовый стиль: light (белое облачко, тёмный текст), dark, glass (полупрозрачный), minimal (без фона).
    preset: light
    # Раскомментируйте любую строку ниже, чтобы переопределить стиль:
    # Цвет фона #AARRGGBB (AA = непрозрачность, 00 = невидимый) или #RRGGBB.
    # background: "#E6FFFFFF"
    # Текст, пока игрок говорит, и законченная фраза. Цвета: &0-&f, &l жирный, &o курсив, &#RRGGBB.
    # partial-format: "&8{text}"
    # final-format: "&0{text}"
    # text-shadow: false
    # Видно сквозь блоки.
    see-through: false
    # Выравнивание текста в облачке: left, center, right.
    alignment: center
    # Пробелы с каждой стороны строки (внутренний отступ).
    padding: 1
    # Размер текста.
    scale: 1.0
    # Маленький хвостик под нижним облачком.
    tail:
      # enabled: true
      # Любой символ: ▼ ▾ ◆ • ⏷ ...
      symbol: "▼"
      # auto = цвет фона, или #AARRGGBB.
      color: auto

  visibility:
    # Кто видит облачка:
    #   voice-chat - только игроки, которым Plasmo Voice действительно передаёт голос (дальность, группы, broadcast)
    #   distance   - все в радиусе fallback-distance
    #   world      - все в том же мире
    mode: voice-chat
    # Радиус, если голосовой чат не сообщает, кто слышит говорящего (и для mode: distance).
    fallback-distance: 24
    # Дальше этого расстояния облачка никогда не показываются.
    max-distance: 96
    # Показывать облачка игрокам БЕЗ мода Plasmo Voice, если они в зоне слышимости
    # (только обычный голос рядом; группы и broadcast им не показываются).
    include-players-without-voice-mod: true
    # Показывать игроку его собственные облачка (видно с вида от третьего лица).
    show-to-self: false
    # Скрывать облачка над невидимыми игроками и наблюдателями, чтобы не выдавать их позицию.
    hide-when-speaker-invisible: true

# Как распознанная речь пишется в облачках и чате. События API всегда получают исходные слова.
display-text:
  # Числа словами -> цифры ("два" -> 2, "двадцать пять" -> 25).
  numbers-to-digits: true
  # плюс, минус, равно, делить, умножить, процент -> + - = / × %
  math-symbols: true
  # Слова, похожие на ник игрока онлайн, заменяются этим ником.
  match-nicknames: true

# Копировать каждую законченную фразу в чат игрокам, которые могли её слышать.
chat:
  enabled: true
  format: "&8[&bVoice&8] &f{name}&7: &f{text}"
  # Отправлять и самому говорящему.
  send-to-self: true

debug:
  # Писать законченные фразы в консоль. Голос никогда не пишется на диск.
  log-transcripts: false
  # Для каждой фразы писать громкость, длительность и ответ движка.
  verbose: false
  # ТОЛЬКО ДЛЯ ОТЛАДКИ: сохранять звук каждой фразы в plugins/PV-Transcribe/debug-audio/*.wav
  # (ровно то, что получил движок). По умолчанию выключено; включайте только временно.
  save-audio: false
```

## Частые настройки

| Что нужно | Команда |
|---|---|
| Русский язык распознавания | `/vtt language ru` |
| Сообщения плагина на русском | `/vtt set locale ru` |
| Самый точный движок (нужен ключ Deepgram) | `/vtt set engine.deepgram.api-key <ключ>`, затем `/vtt engine deepgram` |
| Тёмные облачки | `/vtt set subtitles.style.preset dark` |
| Одно облачко вместо трёх | `/vtt set subtitles.max-bubbles 1` |
| Не дублировать фразы в чат | `/vtt set chat.enabled false` |
| Отключить распознавание в мире | `/vtt world <мир> off` |
| Проверить вид облачка без микрофона | `/vtt demo` |
